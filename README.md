# 🦖 2D Dino Adventure Game

A 2D browser game where you control a dinosaur, jump over obstacles, and chase the high score. Zero dependencies.

## Features
- Dinosaur character with jump controls
- Obstacles to dodge and score tracking
- Restart/replay functionality
- Keyboard controls (Spacebar)
- Runs directly in the browser

## Tech
Vanilla HTML/CSS/JavaScript

## How to Play
- Press **Spacebar** to jump
- Avoid obstacles and survive as long as possible
